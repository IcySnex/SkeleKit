The API reference will be generated from SkeleKit's compiled public surface and XML documentation comments.

The generator pipeline is being designed separately so that generic types, overloads, inheritance and namespace summaries are represented accurately while preserving the desired Markdown format.

For the current public surface, use the source and XML comments in the [SkeleKit repository](https://github.com/IcySnex/SkeleKit/tree/main/Source/Framework/SkeleKit.iOS).
