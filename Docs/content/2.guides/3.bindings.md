---
title: MVVM and bindings
description: Bind views to plain ViewModels without runtime reflection.
icon: lucide:refresh-cw
---

Bindings support one-way, two-way, one-way-to-source and one-time flows, converters, nested paths and configurable update triggers.

```csharp
new Label
{
    Text = Bind<int, string?>(vm => vm.Count, count => $"Tapped {count} times")
}
```

ViewModels only need the standard `INotifyPropertyChanged` and `ICommand` contracts. A SkeleKit-specific base class is not required, and CommunityToolkit.Mvvm works naturally.

This guide will be expanded with binding modes, list bindings, converters and validation patterns.
