SkeleKit applications start with `SkeleApplication.CreateBuilder()`. The builder configures services, appearance and one of three root structures:

- `SinglePage<TView>()` for one root page
- `Stack<TView>()` for navigation-based applications
- `Tabs(...)` for tab and iPad sidebar applications

This guide is being expanded. Until then, the [Gallery source](https://github.com/IcySnex/SkeleKit/tree/main/Source/Samples/SkeleKit.Gallery) shows the complete application shell and every supported navigation pattern.
