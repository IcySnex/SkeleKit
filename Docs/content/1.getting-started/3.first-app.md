The generated `Main.cs` creates the SkeleKit application and chooses its root page:

```csharp
using SkeleKit;

SkeleApplication.CreateBuilder()
    .SinglePage<MainView>()
    .Build()
    .Run(args);
```

A page is a `ContentView` marked with `[Page]`:

```csharp
using SkeleKit;

[Page]
public class MainView : ContentView
{
    public MainView()
    {
        Title = "My app";

        Content = new Grid
        {
            Padding = new Thickness(20),
            Children =
            {
                new Label
                {
                    Text = "Hello World!",
                    FontSize = 32,
                    HorizontalAlignment = HorizontalAlignment.Center,
                    VerticalAlignment = VerticalAlignment.Center
                }
            }
        };
    }
}
```

SkeleKit resolves registered pages through dependency injection, hosts them in UIKit view controllers and realizes the native controls when the page appears.

The next guides will cover application structure, bindings, layout, controls and navigation in detail.
