SkeleKit is a native, code-first UI framework for .NET for iOS. It wraps UIKit controls with a composable C# API and handles the application infrastructure that otherwise sits around them.

You write ordinary C# object trees:

```csharp
[Page]
public class MainView : ContentView
{
    public MainView()
    {
        Content = new StackPanel
        {
            Spacing = 12,
            Padding = new Thickness(16),
            Children =
            {
                new Label { Text = "Hello from SkeleKit", FontSize = 30 },
                new Button { Text = "Continue", Kind = ButtonStyle.Filled }
            }
        };
    }
}
```

SkeleKit turns that tree into native UIKit views. It does not ship a custom renderer and it does not require MAUI or XAML.

## What it handles

- Native controls, layout and styling
- AOT-safe MVVM bindings and commands
- Navigation stacks, tabs, sheets and dialogs
- Collection views, forms and system integrations
- Dark mode, Dynamic Type, safe areas and keyboard avoidance
- Dependency injection, page registration and application lifecycle

## Current status

SkeleKit is an early preview. It is suitable for experimentation and early applications, but APIs may change before 1.0.
