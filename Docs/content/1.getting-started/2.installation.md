## Requirements

- macOS with Xcode
- .NET 10 and the .NET iOS workload
- An application targeting `net10.0-ios` and iOS 18 or later

## Create a project

Install the template package:

```bash
dotnet new install SkeleKit.Templates::0.1.0
```

Create and build an application:

```bash
dotnet new skelekit-ios -n MyIosApp
cd MyIosApp
dotnet build -r iossimulator-arm64
```

The template includes the scene manifest, SkeleKit host, first page, launch screen, entitlements and app-icon catalog.

::alert{icon="lucide:info"}
The main `SkeleKit.iOS` package carries the page source generator and simulator hot-reload targets. You do not need to install them separately.
::

## Add SkeleKit manually

For an existing .NET for iOS project:

```bash
dotnet add package SkeleKit.iOS --version 0.1.0
```

You will also need to configure `SkeleWindowSceneDelegate` in `Info.plist`. The project template is the recommended starting point because it performs the complete setup.
