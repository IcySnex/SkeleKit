title: Mail
description: Present the system mail composer with recipients, a body, and attachments.

---

Inject `IMailer` and pass it a `MailContent` value:

```csharp
public sealed class FeedbackViewModel(IMailer mailer)
{
    public Task<MailResult> SendAsync() => mailer.ComposeAsync(new MailContent
    {
        To = { "support@example.com" },
        Subject = "Feedback",
        Body = "<p>Sent from the app.</p>",
        IsHtml = true
    });
}
```

The composer is the system `MFMailComposeViewController`. Its task completes when the composer is dismissed, with a `MailResult` of `Sent`, `Saved`, `Cancelled`, or `Failed`. Canceling is not an error, so handle `Cancelled` as a no-op.

`CanSendMail` is false when no Mail account is configured and always in the simulator. Composing while it is false throws `InvalidOperationException`, so gate the action on it or fall back to another contact path:

```csharp
if (mailer.CanSendMail)
    await mailer.ComposeAsync(content);
else
    await navigator.OpenUrlAsync("https://example.com/contact");
```

## Recipients

`To`, `Cc`, and `Bcc` are address lists. UIKit silently drops addresses it cannot parse, so invalid entries do not throw.

```csharp
MailContent content = new()
{
    Subject = "Report"
};

content.To.Add("team@example.com");
content.Cc.Add("manager@example.com");
content.Bcc.Add("archive@example.com");
```

## Attachments

Add a `MailAttachment` per file. The MIME type tells the recipient's client how to open it, and the file name includes the extension:

```csharp
content.Attachments.Add(new MailAttachment
{
    Data = await File.ReadAllBytesAsync(path),
    FileName = "report.pdf",
    MimeType = "application/pdf"
});
```

Keep attachments small; many mail providers reject messages over roughly 20 MB. The data is copied into the message, so the source can be released after composing.

`IMailer` is registered with the other built-in services described in [application setup and DI](/guides/application/application-setup-and-di#services), but can also be accessed from any custom view through its protected `Mailer` property.
